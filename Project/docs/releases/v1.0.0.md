# MODU v1.0.0

MODU's first release delivers a complete native Android clothing-store experience backed by reproducible local demo data.

## Highlights

- Browse, search, filter, and sort a paginated clothing catalog.
- Inspect product details, related products, variants, stock, and quantities.
- Manage a persistent cart with update, remove, restore, and clear operations.
- Complete a locally simulated checkout without external services or credentials.
- Run the `demo` flavor offline using a versioned Room catalog and bundled assets.

## Engineering

- Layered presentation, domain, and data architecture with Hilt dependency injection.
- Kotlin coroutines and Flow for asynchronous and reactive state.
- Room, Paging 3, ViewBinding, and flavor-specific data implementations.
- Automated tests and reproducible builds validated by GitHub Actions.
- Signed `demoRelease` APK verified before automated GitHub Release publication.
